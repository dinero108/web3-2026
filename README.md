# 패스폴리오 · web3-2026

청소년의 경험을 기록하고 진로 탐색을 계속 이어가는 웹앱입니다.

## 사용하기

GitHub Pages 주소: https://dinero108.github.io/web3-2026/

이 저장소의 실행 파일은 별도 서버 없이 동작합니다. Pages 설정은 **Deploy from a branch → main → /(root)**입니다.

## 진로 로드맵

첫 탐색 → 심화 탐구 → 프로젝트 실행 → 포트폴리오 정리의 4단계, 분야별 12개 미션으로 구성됩니다. 현재 단계의 세 미션을 마치면 다음 단계가 자동으로 열립니다. 전체 완료 후에도 직접 세 미션을 설계해 다음 도전을 계속할 수 있습니다.

관심 분야별 진행 상태와 기존 첫 단계 완료 기록을 유지합니다. 완료를 취소하면 이후 단계는 잠기지만 기록은 보존됩니다.

## 기록 저장

개인 기록은 현재 기기와 브라우저에 저장됩니다. GitHub 저장소에는 업로드하지 않습니다. 다른 기기로 옮기기 전 나의 포트폴리오에서 기록 내려받기로 백업하고, 새 기기에서 기록 가져오기를 사용해 주세요. 공용 브라우저에서는 사용 후 기록을 삭제해 주세요.

## 소스코드 수정

`pathfolio-source.zip`에 수정 가능한 React/TypeScript 소스, 테스트, 설치 잠금 파일과 GitHub Actions 배포 설정이 들어 있습니다. 압축을 별도 폴더에 풀고 Node.js 24에서 실행합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

소스 프로젝트를 저장소 최상위로 옮길 때에는 기존 실행용 index.html과 혼합하지 말고, README의 소스 배포 안내에 따라 Pages의 Source를 GitHub Actions로 변경합니다.

## 현재 제공 범위

활동·독서·프로젝트 기록, 관심 분야 선택, 단계별 로드맵, 후속 도전, 진행 저장, PDF 인쇄, JSON 백업·복원, 기록 삭제.

추천은 규칙형이며 생성형 AI 분석, 기관 인증 및 블록체인 SBT 발급은 연결되지 않았습니다. 미션 완료는 본인 체크입니다.
